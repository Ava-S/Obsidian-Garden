## Definition
- Object-centric process mining works on discrete events
- They represent various actions or activities that occur within a system or process

## Atomicity
- Events are atomic (i.e. do not take time)
## Event Types
- Events are typed
- Events are categorized into different types based on their nature or function
	- For example, a procurement process might have event types such as Order Created, Order Approved or Invoice Sent
- Each event type represents a specific kind of action that can take place in the process
- Each event is exactly one type
- Sometimes, we use the term *activity* to refer to an event type
## Time
- Events have a timestamp
## Event attribute values
- Events may have additional attributes
## Uniqueness + event identifiers
- Every event is unique and corresponds to a specific action or observation at a specific point in time
- They have event identifiers
