### Where did I get stuck/faced difficulties?

- I got stuck on reasoning on events and their identifiers. In a lot of data sources I have encountered, events do not have an ID. It just seems that this is not really common to do. So, it seems that there is the assumption that every recording corresponds to a single unique event. However, from experience we know this assumption does not always hold. Of course, we have duplicate event recordings as a result of convergence, but we could also have multiple sensor recordings that indicate a single event. So, for some datasets, and dependent on the analysis, some event resolution has to happen. I'm just not sure how far to take this, because I don't want to end up in a rabbit hole. I'm also afraid that there is some literature available on this that I'm not able to find.
- I'm not sure how to start answering the question of what this conceptual model should do in the end. To be frank, I keep on getting stuck on what you exactly mean with conceptual model, let alone on what its goal is. But I don't really know how to start tackling this question, I think mainly because it is such a broad question. What I've been doing up until now is mostly writing down in what shape records occur and what we expect for events and objects and how these map to each other. However I don’t know how this then relates to concepts.
